# Zotero 当前分类自动编号

这是一个用于 Zotero **Actions & Tags** 的自定义动作。选中左侧的一个分类，再选中其中一篇尚未编号的文献，动作会参考该分类**直接收录**的其他文献，在“标题翻译”列续号。

脚本：[current-collection-auto-number.js](./current-collection-auto-number.js)

## 工作方式

- 从当前分类已有文献的“标题翻译”开头读取编号，例如 `B01`、`A20`、`SF03` 或纯数字 `20`。
- 仅在某一前缀占**已识别编号的严格多数**时，沿用它的最大序号加 1，并保留原有补零宽度。例如 `B28 → B29`、`A09 → A10`、`09 → 10`。
- 原来有译名时，将新编号放在译名前，例如 `供应链韧性研究 → B29｜供应链韧性研究`。
- 同一篇文献即使被加入多个分类，也只修改这**一个 Zotero 条目**的标题翻译。编号取决于运行时选中的分类；此脚本**不保证全库唯一编号**。

## 安装

1. 在 Zotero 中安装并启用 **Actions & Tags** 插件。
2. 打开插件的动作设置，新增动作，名称可填“文献自动编号”。
3. **事件**选择“无”；**操作**选择“脚本”或 `customScript`；将 [脚本文件](./current-collection-auto-number.js) 的**全部内容**复制到“数据”中。不要只填文件名或网址。
4. 如需右键菜单入口，在“菜单项”填“当前分类自动编号”，勾选“**条目菜单中**”。勾选“启用”，然后保存。
5. 如需快捷键，可在“快捷键”栏设置 `⌘B`；若与现有快捷键冲突，换用其他组合键。快捷键由插件设置，脚本本身无需修改。

## 使用

1. 在左侧点击**一个具体分类**，不要停在“我的文库”、父级汇总视图或搜索结果。
2. 在中间列表只选中**一篇**直接属于该分类、尚未编号的文献主条目，不要选 PDF 附件或笔记。
3. 右键该文献，选择“**触发动作 → 当前分类自动编号**”；或者按设置好的快捷键。
4. 查看提示，并在“标题翻译”列确认结果。首次使用建议先拿测试条目试运行。

## 何时停止并提示手动处理

- 当前分类没有可识别的旧编号，或不同前缀没有严格多数。
- 胜出的前缀已经存在重号；目标文献已有开头编号；标题翻译元数据重复。
- 当前视图不是单个分类、一次选择了多篇，或选中的是附件、笔记、非当前分类直接收录的条目。

此时动作不会为目标文献写入新编号。纯数字编号后接译名时，请加空格或 `｜` 等分隔符，例如 `20｜译名`；避免把“2026年……”误认作编号。

## 存放位置与维护

脚本通过 Zotero `Extra` 中的 `titleTranslation:` 字段读写“标题翻译”，保留其他 Extra 行。整理分类时建议先决定文献的主要归属，再编号；之后把同一条目加入其他分类不会生成第二个独立编号。已有编号不随分类移动而自动重排。

本脚本的编号规则已用模拟条目检查；尚未在你的实际 Zotero 文库中逐条验证。使用前请备份文库，并用少量测试条目确认插件版本与字段显示符合预期。
